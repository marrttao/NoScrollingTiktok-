# Установка Unscroll

[← О проекте](../README.md) · [APK и обновления в Telegram](https://t.me/SayNoToScrolling)

> [!IMPORTANT]
> Предварительная версия для TikTok 47.4.3. Применение всех шести патчей и
> внедрённый код проверены — смотри [отчёт](TEST_REPORT.md). Работа на телефоне
> ещё не проверена. Перед установкой проверь [совместимость](COMPATIBILITY.md)
> и статус конкретной версии в канале.

## 1. Где взять APK

Открой **[@SayNoToScrolling](https://t.me/SayNoToScrolling)** в Telegram.
Найди публикацию с APK-версией мода и прочитай её описание: версию TikTok,
совместимость и известные ограничения. Если APK ещё не опубликован, следи за анонсами.

Исходный код остаётся на GitHub. Для самостоятельной сборки и применения патчей
используй [инструкцию для разработчиков](BUILD.md).

## 2. Перед удалением TikTok — сохрани данные

Unscroll сохраняет пакет `com.zhiliaoapp.musically`, но подписывается другим ключом.
Поэтому Android не позволяет установить его поверх официального TikTok.
**Удаление приложения стирает локальные данные, включая черновики.**

| Данные | Что произойдёт при удалении |
| --- | --- |
| Аккаунт, подписки и опубликованные видео | Остаются на серверах TikTok |
| Личные сообщения | Серверная история должна загрузиться после входа |
| **Неопубликованные черновики** | **Будут удалены, если заранее их не сохранить** |
| Локальные настройки, кеш и офлайн-видео | Будут удалены |
| Текущий вход в аккаунт | Потребуется войти заново |

Перед удалением:

1. Открой профиль и черновики. Сохрани нужные видео в галерею или опубликуй их с
   доступом «Только я». Убедись, что копии сохранились.
2. Проверь пароль и доступ к привязанному телефону или почте. Для входа через Google
   предусмотрен браузерный сценарий, но его работа на устройстве пока не проверена;
   подготовь запасной способ входа.
3. Убедись, что доступен второй фактор, если включена двухэтапная проверка.
4. Прочитай описание APK в канале и [известные ограничения](COMPATIBILITY.md).

## 3. Установи APK

1. Выполни проверку из раздела 2.
2. Удали официальный TikTok. Если переходишь с другой модификации с отличающейся
   подписью, её также придётся удалить.
3. Открой APK из публикации в [канале](https://t.me/SayNoToScrolling).
4. Если Android запросит разрешение на установку из этого источника, выдай его для
   установки выбранного APK. После установки разрешение можно отключить.
5. Открой приложение и войди в аккаунт.

При ошибке «Приложение не установлено» проверь, не остался ли TikTok или другой мод
с несовместимой подписью. Дополнительная диагностика — в
[Troubleshooting](TROUBLESHOOTING.md).

## 4. Обновления

Новые APK-версии и инструкции ищи в
**[Telegram-канале @SayNoToScrolling](https://t.me/SayNoToScrolling)**.
Перед обновлением сохрани черновики и проверь описание версии.

Обновить приложение поверх установленного можно только при совпадении пакета и
ключа подписи и совместимой версии APK. Если ключ изменился, потребуется удаление
с потерей локальных данных. Не удаляй приложение, пока не сохранишь нужные данные.

Официальные обновления из Google Play не устанавливаются поверх APK с другой
подписью. Автообновление TikTok можно отключить на его странице в Google Play.

## 5. Если собираешь самостоятельно

Следуй [инструкции по сборке и патчингу](BUILD.md). Сохраняй свой keystore и
используй его при следующих сборках. Самостоятельная сборка и APK из канала могут
иметь разные подписи: переход между ними может потребовать удаления приложения.

## 6. Возврат к официальному TikTok

Сохрани черновики, удали Unscroll и установи TikTok из Google Play.
При удалении Unscroll его локальные данные также будут стёрты.
